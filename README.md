# photonetc

Tools to handle, analyze, and visualize photonetc data cubes.

## Installation

```console
pip install git+https://github.com/Weber-Microscopy-Group/photonetc.git
```

## Scripts

### Convert temporal to spectral cubes

```sh
photonetc-convert-temporal-to-spectral
```
