# photonetc

Tools to handle, analyze, and visualize photonetc datacubes.

## Installation

```console
pip install git+https://github.com/Weber-Microscopy-Group/photonetc.git
```

## Scripts

### Convert temporal to spectral cubes

```sh
photonetc-convert-temporal-to-spectral
```

## Examples

Look in the [`tests`](/tests/) directory for usage.
